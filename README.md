# Web Scraping and Data Visualization

This project uses Python to collect and analyse information about major U.S. companies from web-based data.

## What I worked on

- Scraped company information from a web page using Python.
- Cleaned and organized the extracted data.
- Explored company revenue, growth, and employee-related metrics.
- Calculated revenue per employee for comparison.
- Created visualizations to make the results easier to understand.

## Tools used

- Python
- Jupyter Notebook
- BeautifulSoup
- Pandas
- Matplotlib

## File

- `web_scraping_visualization.ipynb` — contains the notebook and analysis.
